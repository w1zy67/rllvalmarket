RIVALMARKET MINI APP — ЗАПУСК НА WINDOWS 11
==========================================

ВАЖНО
- Не отправляйте токен бота в чат и никому его не показывайте.
- Этот проект — стартовый шаблон с демонстрационными товарами.
- Баланс, покупки, платежи и поддержка пока не работают как реальные сервисы.
- Для публикации Mini App нужен публичный HTTPS-адрес.

1. Установите Node.js LTS:
   https://nodejs.org/
   Во время установки оставьте включённым добавление Node.js в PATH.

2. Распакуйте архив в папку, например:
   C:\\RivalMarket

3. Откройте эту папку в Проводнике. В адресной строке напишите cmd и нажмите Enter.

4. Выполните:
   npm install

5. Создайте файл .env:
   - скопируйте .env.example
   - назовите копию .env
   - откройте .env в Блокноте
   - вставьте токен от @BotFather в BOT_TOKEN
   - пока оставьте WEB_APP_URL=https://example.com
   Не публикуйте .env и не отправляйте его другим людям.

6. Запустите сайт:
   npm start

7. Откройте в браузере:
   http://localhost:3000

ПОДКЛЮЧЕНИЕ К TELEGRAM
1. Сначала разместите сайт на хостинге, который выдаёт HTTPS URL.
2. В .env укажите настоящий адрес:
   WEB_APP_URL=https://ВАШ-ДОМЕН
3. Перезапустите npm start.
4. Отправьте своему боту /start — он покажет кнопку «Открыть магазин».
5. Дополнительно в @BotFather можно настроить Menu Button через /setmenubutton
   и указать тот же HTTPS URL.

ПРОВЕРКА
- http://localhost:3000/api/health должен вернуть {"ok":true,...}
- Telegram Mini Apps требуют HTTPS для публичного запуска.
- Не используйте демо-баланс как реальные деньги.
- Перед реальными заказами добавьте базу данных, проверку Telegram initData
  на сервере, контроль доступа администратора и платёжного провайдера.
